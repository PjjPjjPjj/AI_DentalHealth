## 3. 内容核验（核心问题：是否健康牙面）

- **225 张缩略图墙全量目检 + 9 张原图抽检：全部为清洁无斑牙面** ✅
- 构图：口内正面视角为主（牵拉器/拉钩），少量口镜照；以前牙区为主，**无咬合面/后牙颊面视角**
- 牙面状态：菌斑基本不可见；少数牙有充填体/贴面/轻度拥挤（非菌斑，但高光形态需注意）
- 与"健康"命名语义一致，**可信度高**；建议入库前做一轮快速人工复核兜底

## 5. 对特异度问题的价值判断

**这是真正可用的阴性数据源**，与上一批（视频帧）本质不同：

1. **域匹配**：临床 Canon 画质，与测试域一致，不会引入"模糊=阴性"捷径
2. **语义正确**：整库即"健康"标签，与特异度所需的阴性定义直接对应
3. **产能估算**：202 张唯一图 × 每张可见 10~14 颗前牙 ≈ **2,000~2,800 个阴性牙面 crop**（配合牙齿分割取 crop），其中干净的即现有 n=56 阴性评估集的 **10~50 倍扩容** → 特异度置信区间大幅收窄

### 使用建议（按优先级）

| 用途 | 做法 | 注意 |
|---|---|---|
| **① 扩充阴性评估集**（首推） | 牙齿分割→整牙 crop→现有 plaque 模型预筛→人工快审→入 test-neg-SANO | 去重后使用；与现有 test 严格分离报告（双口径） |
| ② 训练集阴性扩充 | 同上入 train | 需控制混入比例，防域外负迁移（本集光照/构图与训练域仍有差异） |
| ③ OOD 泛化口径 | 直接全图推理 | 与视频帧集共用 OOD 报告框架 |

### 风险与限制

- 标签为**目录级弱标签**，个别图可能有轻度色素/充填体高光——入库前人工复核必须有
- 视角集中在前牙正面，后牙区阴性覆盖不足（与现有集阴性集中在 11/21/41/31 恰好互补）
- 出处/license 未附（疑似独立临床拍摄收集），正式对外成果前需确认授权
- 评估集若混入同患者多图（823 编号连续段），存在**图级相关性**——报告 Spec 时按图聚类 bootstrap
