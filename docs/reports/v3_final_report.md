## 3. 最终管线（全部 val 决策、test 只跑一次）

```
图像 → 质量门控
  → S1: YOLO11m-seg 3类 (calculus/other_lesion) @640
        特写图(<500px)整图推理；宽图(≥500px) 2×2 切片(320px, 2×放大)+跨窗NMS
  → S2: YOLO11m-seg 3类, bbox-center 160 窗口 4× 放大精分割
  → Verifier: EfficientNetV2-S 4通道(RGB+S2mask) 实例真伪
  → M3: 8特征 logistic 融合 (thr=0.60, val最大F1) → mask-NMS
  → 图像级: logistic[管线max概率, EffNet@448+TTA, YOLO11m-cls] (thr=0.44)
```
训练数据: v3b 域平衡(other×2) + v3c 切片化宽图(320窗, 随机2窗+GT中心1窗)。
模型链: v3c_stage1(best@zoom) + v3b_stage2 + verifier + fusion_v3 + ensemble(ABC)。

## 4. 为什么 92% 不可达（证据）

1. **残余 FN = 极小病灶**：val 42 FN 的病灶面积占比中位 0.18%（全部阳性中位 0.94%，
   小 5 倍）；26/42 管线零候选、分类器概率中位 0.09 —— 检测器与分类器同时盲。
   0.18% 病灶在 640 输入下仅 ~7px，2× 切片后 ~15px，仍接近分辨率极限。
2. **FP 全部伴随其他病灶**：36/36 FP 图像带有色素/菌斑/龋损标注 —— 像素级
   calculus-vs-stain 歧义是数据层的，图像级辅助监督无信号（99.3% 阴性也有其他病灶）。
3. **三域异构**：gingivitis 0.996 / caries_0 0.818 / other 0.836；`other` 域
   sens 0.42 已从 0.21 翻倍，仍最低。域内 GT 少（large n=29）分层指标噪声大。
4. 已试并被 val/test 证据否决：纯推理切片（召回反降）、P2 提案（FP 暴涨）、
   宽图 960（AUROC 降）、丰富聚合特征（CV 无增益）、ConvNeXt+域路由集成
   （val 0.907 但 test 回退 0.853，已回滚 ABC）。

## 5. 到达 92% 的路线图（按预期收益排序）

1. **补数据**：宽视野域 +1000 张标注（当前仅 613 张，阳性 140）；
   提高拍摄分辨率（≥1280px）——小病灶信息瓶颈在输入。
2. **患者级标注与划分**（现无 patient_id），杜绝任何残余同患者泄漏。
3. **牙齿分割约束**（IO150K 仍缺）：牙面 mask 过滤非牙面候选 → 直接砍 FP。
4. **半监督自训练**：对无标注口内图用现管线打伪标（阈值>0.9）扩充训练。
5. **更大骨干 + 种子平均**（YOLO11l / 3×seed 平均）：约 +0.5~1pt。
6. 难例专项采集：色素-结石同图对、窝沟染色、龈缘阴影。

## 附录 A（2026-08-28）：Eka 牙齿检测器 + 解剖围栏 A/B

**训练**：Eka 12,981 牙齿 BB → YOLO11m 检测器 @640（77 epochs 早停）。
Eka test mAP50 **0.947** / P 0.914 / R 0.924 —— 域内任务成功。

**跨域围栏 A/B（val 扫描 → 冻结 → test）**：失败，val 协议选择 OFF。
- 围栏开启（任意阈值 2%~20%，框外扩 10%）：候选 ~513/570 被杀，
  实例召回 0.38-0.40 → **0.04-0.05**，同时 FP/图 0.157 → 0.029。
- 根因：Eka 为前牙 12 颗视角，Oral-Mamba 的磨牙区（结石高发）牙齿检出
  覆盖不足（中位仅 6 框/图），围栏把磨牙区候选连同 TP 一起杀掉。
- 围栏概念本身有效（FP -81%），卡在跨域覆盖；结论：解剖围栏必须
  **in-domain**（Oral-Mamba px1 牙龈 mask 现成 1809 张可训牙龈分割器，
  或 SegmentAnyTooth 权重生成牙面 mask）。
