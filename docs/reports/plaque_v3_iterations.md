## 2. 各项尝试的发现

### 2.1 难阴性挖掘（v3_mined）——❌ 证伪，重要教训

- 从 939 张 train base 图用牙齿分割挖无 GT 重叠、v2 打分 P∈[0.70,0.95] 的边缘 crop
  → **881 个候选中绝大多数是正畸托槽牙**（金属托槽/弓丝触发误报）
- 复核 270 张确认干净后作为阴性微调 → **AUROC 0.896→0.835，testExt Spec 崩至 0.164**
- 根因：**语义冲突**。原 GT 中托槽牙上的菌斑被标为阳性（框级标注按"有无菌斑"），
  而"托槽→阴性"的整牙标签与之直接矛盾，破坏了原域排序能力
- 沉淀：框级 GT 语义下，整牙级挖掘阴性必须避开"托槽/修复体"等 GT 内见过的形态；
  若要利用托槽数据，需按"托槽周围菌斑"子区域级标注，属标注协议升级，暂缓
- 产物保留：`scripts/mine_plaque_hard_negs.py`、复核 sheet `annotation_queue/mined_neg_review/`

### 2.2 val 阴性扩充——✅ 采纳（进入 v3c/v4 协议）

- 20 张 SANO train 图（503 crop）移入 val：val 阴性 96→599，冻结阈值噪声显著收窄
- v2 协议冻结点漂移（0.48 vs 0.70）的根源即 val 阴性过少，此改动永久保留

### 2.3 SANO 模糊/暖色稳健变体（v3c）——✅ 技术成功但无部署增益

- 每个 SANO train crop 生成 1 个确定性变体（高斯模糊 或 暖色+压暗，md5 选型）
- 已修复并审计一处 train↔val 近重复泄漏（变体跟随原图移 val，503 个已删除）
- AUROC 0.8965（微升）、SANO 0.9904（微升）、但 testExt 同 Sens Spec 更低
- 结论：v2 的 SANO 原生阴性已足以修复模糊/暖色捷径；离线变体冗余
