数据集：**"Teeth or Dental Image Dataset"**（外层 zip 嵌套内层 `Mendeley dataset 19.4.2024.zip`，1.36 GB）
来源疑似 Kaggle 同名数据集（从网络/视频收集的口内照片，按视角分目录），**无任何 README/license/伦理文件，出处待确认**
审计日期：2026-09-03；关联问题：plaque_bin_v1 特异度受阴性样本稀缺限制（Spec 0.554，n=56）

## 3. 图像质量（核心短板）

| 项 | 本数据集 | 现有 Mendeley 多模态集（对照） |
|---|---|---|
| 分辨率 | 1024~1280 × 550~768；**79% 为 1280×550 视频帧规格** | 中位 6240×4160（26MP 单反） |
| 清晰度（Laplacian 方差，抽样） | **中位 16**；97% < 100（模糊），79% < 30（严重模糊） | 中位 **759**（模糊仅 12%） |
| 内容 | 真实口内照（开口器牵拉），成人+儿童混合，多数可见菌斑/色素/结石 | 标准化临床拍摄 |

结论：与训练/测试域存在**约 47 倍的清晰度鸿沟**，菌斑纹理这一判别性信号在多数图上已被运动模糊+压缩破坏。

## 4. 对"牙菌斑特异度"问题的适用性判断

### 4.1 不能直接当阴性训练数据

1. **无标签**——不能假设"无标注 = 无菌斑"；抽检可见大量牙齿带菌斑/色素/结石，盲目标为阴性会引入 30%+ 标签噪声
2. **域捷径风险**——模糊视频帧 crop 与 DSLR 测试图判然有别，模型极易学到"模糊 → 阴性"捷径：在这批图上 Spec 虚高，对真实测试域（Spec 0.554 的 n=56 阴性）**无实质帮助，甚至可能因特征漂移而回退**
3. **阴性纹理被破坏**——特异度提升需要"难阴性"（干净牙面的高光、釉质发育不良等易误报纹理），本数据集的模糊恰好抹平了这些纹理，挖不出难阴性

### 4.2 有限的使用价值

- ✅ **域外压力测试集（OOD gallery）**：用当前模型对 9.5k 图跑全图/crop 推理，人工复核误报——检验模型在陌生成像条件下的过触发程度，作为"泛化特异度"参考口径
- ✅ **去模糊筛选后的人工阴性小库**：按清晰度取 top 分位（p90 也仅 ~50，可用但量少），人工确认无斑牙面 crop，可补充 100~300 个经人工验证的阴性 crop（需人工标注成本）
- ❌ **不建议**直接混入训练集重训

### 4.3 特异度问题的更优路径（本数据集之外）

1. 现有 Mendeley 集**增强变体阴性**已纳入（val 85/test 364），继续沿用 extended 口径
2. 从现有 26MP 图中用牙齿分割挖**框外阴性区域**（龈缘外、未标注健康牙面）
3. dental disease detection 数据集中的 normal 图可产生跨域阴性 crop（需确认标注质量）

## 5. 结论

| 维度 | 评分 | 说明 |
|---|---|---|
| 完整性 | ★★★★★ | 零损坏 |
| 标注可用性 | ☆ | 无任何标注 |
| 图像质量 | ★☆ | 视频帧级分辨率+严重模糊，远低于现有域 |
| 与项目域匹配 | ★☆ | 零重叠但域差距大 |
| 对特异度问题的价值 | ★★ | 仅限 OOD 压测/人工筛选小规模阴性 |

**总评：不推荐用于训练改进特异度；建议保留为 OOD 压测图库，特异度提升转向现有数据集内的难阴性挖掘。**
