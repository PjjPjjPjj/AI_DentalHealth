## 第 2 页｜数据集展示（一）：主训练/评估集

**页面要点**
- 学术多模态菌斑数据集：**10,450 张** 口内照（26MP 单反），**148 名患者**，9 个口内视角
- **133,824 个框级标注**（plaque 0/1 + FDI 牙位），共 32 牙位中覆盖 20 个 FDI 位

- 【配图建议】九视角蒙太奇（每视角 1 张）+ 标注框叠加示例 2 张 + FDI 牙位分布条形图
  （11/21/41/31 前牙区标注最密）

**讲解词**
这是菌斑检测领域规模最大、合规链最完整的数据集之一：伦理批件、知情同意、
临床记录齐备。患者级划分保证测试集患者从未在训练中出现。

**页面底部小字**：数据构建脚本 `scripts/build_plaque_bin_v1.py` ｜ 分析报告 `outputs/reports/plaque_dataset_analysis.md`

## 第 4 页｜模型结构（一）：检测管线

**页面要点**
- 【配图建议】横向管线图：
  `口内照 → 质量检查 → 牙齿实例分割 → (牙结石分割 ∥ 龋齿检测) → 牙菌斑分类 → 关联输出 JSON`
- 菌斑路径：牙齿分割提供牙位 bbox → 整牙裁剪 → 二分类 → P(plaque)
- 设计要点：**训练与线上同一条裁剪路径**（无 train/serve skew）
- 实证：分割牙位 crop 路径的判别力 **优于** 标注框直裁（AUROC 0.916 vs 0.868）

**讲解词**
菌斑分类天然依赖"牙在哪"，因此管线把它挂在牙齿分割之后。整牙视野比局部
小条带更可分——这条路径的选择本身就是一个被实验证伪/证实过的设计决策。

## 第 5 页｜模型结构（二）：分类器与校准头

**页面要点**
- 骨干：YOLO11s-cls，**5.45M 参数**，输入 224×224，单帧推理 <1ms
- 结构：【配图建议】conv stem → C3k2 阶段（下采样×4）→ GAP → 2 类线性头
- 输出：P(plaque)，经 **Platt 校准** 后输出：
  `logit(P′) = 0.4695·logit(P) + 0.6801`（校准集不参与训练）
- 校准质量：ECE **0.040 → 0.012**；输出即"跨设备可比的真概率"
- 体系内两套阈值：牙级 0.746（校准刻度）／图级独立标定（P5 规则）

**讲解词**
分类头之前是标准 YOLO 分类骨干；真正的设计增量在输出端——校准层让"0.7"
成为一个可对临床沟通的概率，而不是一个内部分数。校准参数是模型资产的一部分，
与权重一起交付。

**页面底部小字**：权重 `outputs/plaque_bin_v2_sano/weights/best.pt` ｜ 校准 `calibration_platt.npz` ｜ 推理封装 `src/inference/models.py#PlaqueModel`

## 第 6 页｜算法指标（一）：框级主表

**页面要点**（官方 test，患者级隔离，2,892 框 = 2,472+ / 420-）

| 指标 | 数值 |
|---|---|
| AUROC | **0.8958** |
| AP | **0.9973** |
| Sensitivity | **0.937** |
| Specificity | **0.560** |
| Precision / F1 | 0.926 / 0.932 |

- 阈值画像（校准刻度）：thr 0.5→0.95 对应 Sens 0.976→0.772、Spec 0.302→0.876（业务可调）
- 部署点 0.746 = "漏诊≤5% 前提下特异度最大"的筛选优先档

**讲解词**
AP 0.997 说明高置信区几乎不出错；AUROC 0.90 是逐牙排序能力。Specificity 要放在
语境里讲：该测试集的阴性是"菌斑牙内部的干净子区域"，属高歧义样本——
逐牙提示看 Sens，筛查提示看第 8 页的图级口径。

## 第 7 页｜算法指标（二）：跨域泛化

**页面要点**（外部健康牙面集，1,148 个健康牙 crop / 46 张图，全阴性）

| 指标 | 数值 |
|---|---|
| Specificity | **0.978**（CI95 0.965~0.989，按图聚类 bootstrap） |
| 健康牙误报率 | **2.2%**（25/1,148） |
| P(plaque) 中位 | **0.023** |

- 该集与训练子集哈希级隔离，专测"陌生设备下的健康牙"判读
- 置信区间用按图重采样：同一患者多牙位的相关性已被保守处理

**讲解词**
跨域泛化是筛查产品真正的命门。健康牙误报率 2.2%、P 中位数 0.023——
模型对"干净"的判信在这个域上和在同域测试集上行为一致。

## 第 8 页｜检测能力：双层输出与图级筛查

**页面要点**

| 口径 | Mendeley test（205 阳性图） | 外部健康集（46 图） |
|---|---|---|
| mean-P（全口均分，推荐筛查） | Sens **0.966** | Spec **1.000**（0 误报图） |
| max-P（最差牙决定） | Sens **0.980** | Spec 0.978（1 误报图） |

- 牙级输出：逐牙 present/score（配 JSON 示例截图）
- 图级输出：全口均分 + 筛查提示；单牙误报被全口平均稀释
- 两种聚合器并存，按产品形态选择："不漏牙"用 max-P，"少打扰"用 mean-P

**讲解词**
同一条校准分数，两种聚合、两套独立标定的阈值，分别对应"逐牙提示"和"整图筛查"
两种产品形态。图级 mean-P 在健康口内照上零误报，同时阳性图召回 96.6%。

## 第 9 页｜典型案例（demo）：四类判读

**页面要点**（每类 1 张配图：原图 + 牙位 crop + P 值角标）
1. **高置信菌斑牙**：P≈0.99，龈缘黄白生物膜清晰 —— 正确拦截
2. **健康前牙**：P<0.05，光洁釉质高光 —— 正确放行
3. **跨设备健康口**（Canon R50 来源）：整口低分 —— 无跨域误报
4. **边界案例**：过曝/轻度色素 —— 分数落中间带，体现"不确定区"真实存在

**讲解词**
四个案例覆盖能力的四个面：抓得住、放得对、换设备稳、边界诚实。
第 4 类是给评审看的：模型知道自己不确定，这是校准带来的副产品。

**页面底部小字**：
`python demo_plaque.py --n 3 --seg`（每案例两图：牙齿分割面板 + 判定卡片）｜
`python demo_plaque.py --verify 100 --seed 42`（随机抽样 vs 人工标注一致率自检）｜
`python demo.py --image demo_images/test.jpg`（全管线单图演示）

## 第 10 页｜实验结果（一）：数据构成消融

**页面要点**（固定训练配方，唯一变量 = 外部健康阴性）

| 配置 | test AUROC | test Spec(420-) | 外部健康 Spec(1,148) |
|---|---|---|---|
| 仅主数据集 | 0.8950 | 0.543 | 0.348 |
| + 外部健康阴性（**最终**） | **0.8958** | **0.560** | **0.978** |

- 结论：外部阴性在**不牺牲原域任何指标**的前提下，把跨域特异度修复 3 倍

**讲解词**
这是本方案最核心的一组实验：一行之差，跨域 Spec 从 0.35 到 0.98，
而主口径纹丝不动——说明学到的是"什么不是菌斑"的普适形态，而非决策边界平移。
