# 牙菌斑检测数据集分析报告

数据集：Mendeley **"A new multi-modal dataset for Dental Plaque Diagno"**
（两卷 zip→7z，共 21.6GB；含 clinical_records、legal_documents、metadata、data_splits.csv）
审计与转换代码：`scripts/audit_plaque_mendeley.py`、`scripts/build_plaque_bin_v1.py`

---

## 1. 来源与合规

- 学术数据集（Mendeley Data），附 **legal_documents/（306 份伦理批件+知情同意）** 与
  **clinical_records/（148 份患者临床记录 docx）**——合规链完整
- 148 名患者（patient0001~0152，缺 0028/0046 等），每患者约 7~9 个口内视角

## 2. 规模与结构

| 项 | 数值 |
|---|---|
| 图像总数 | **10,450 张**（Part1 5,277 + Part2 5,173，md5 校验后无重复计数） |
| 干净 base 图 | 1,319（其余 9,131 为官方增强变体） |
| 标注框总数 | **133,824**（每图均值 12.8 框） |
| 标注形式 | 每框一行：`plaque(0/1) cx cy w h tooth_id(1→FDI 映射)` |
| 官方 split | train 7,538 / valid 1,266 / test 1,646（base：950 / 162 / 207） |
| 患者级隔离 | ✅ **148 名患者跨 split 泄漏 = 0**；md5 跨 split 重复 0；dHash 近重复仅 4 组 |

- 图像质量：**全数据集 0 张损坏、0 张无法解码**；分辨率极高——
  中位 **6240×4160（26MP 单反）**，最小 2560×1920
- 9 个口内视角均匀分布（central/top/bottom × left/middle/right，每视角 836~1312 张 base）

## 3. 官方增强变体（每张 base 派生 ~8 张）

`brightness-down / brightness-up / rotate-left-15 / rotate-right-15 / flip_horizontal / blur / light / dark`
→ 训练可全用；**验证/测试只用 base 干净图**（本项目的保守协议）

## 4. 标注统计（核心）

### 4.1 类别极度失衡（本数据集最大特征）

| split | plaque=1 框 | plaque=0 框 | 阳性占比 |
|---|---|---|---|
| train | 94,158 | 2,202 | 97.7% |
| validation | 16,248 | 96 | 99.4% |
| test | 20,700 | 420 | 98.0% |

阴性框只占 ~2%，且**阴性强依赖增强变体**：val 干净 base 图里阴性框仅 11 个
（96 个中 85 个在增强变体上）；test 干净 56 / 420。

### 4.2 标注粒度

- 一颗牙常对应**多个框**（整体冠 + 龈缘条带等子区域），33,456 个（图×牙位）实例组中
  **2,016 组组内 0/1 标签混合**（同一颗牙部分区域有菌斑、部分没有）
- 推论：**牙位级聚合在此数据上不成立**（val/test 不存在"全阴性牙"）——
  这就是任务形式定为"框级二分类"的直接依据

### 4.3 牙位（FDI）分布

- 使用了 20 个 FDI 位；前牙区为主：11(14.9k)、21(14.9k)、41(10.9k)、31(10.5k) 框最多
- 阴性框也集中在 11/21/41/31（480/516/234/144）——下前牙区（菌斑最常见部位）标注最密

## 5. 质量审计发现（及处理）

| 发现 | 规模 | 处理 |
|---|---|---|
| 标注坐标越界 | 76 框（<0.06%） | 裁剪时 clip，无实际影响 |
| 命名大小写不一致 | `Patient0033` 图像目录 vs 小写标签目录 | 大小写不敏感匹配（审计 v2 已修） |
| 源图损坏 | Part1 内 1 张（zip CRC 错误） | 排除并记录 |
| 空 label 文件 | 21 张（val 6 / test 2 / train 14） | 语义不明（全干净？漏标？），不假设为阴性，排除 |
| bbox 越界/非法 | 少量 | clip 处理 |
| FDI 映射 | metadata/teeth_position_mapping.json，32 牙位中用 20 | 直接采用 |

## 6. 转换后的训练集（plaque_bin_v1，框级二分类）

设计：每个标注框 = 一个样本；官方 split；train 含全部官方增强变体、val/test 仅 base
（但 val/test 的**阴性框**保留增强变体版本并标记 is_aug，扩充稀缺阴性评估集）

| split | plaque(1) | normal(0) | 说明 |
|---|---|---|---|
| train | 94,018 | 2,202 → **19,818**（×8 过采样后） | 共 113,836 crops |
| val | 1,919 | 96（11 base + 85 增强变体） | 训练期重平衡到 1:1 防 best 塌缩 |
| test | 2,472 | 420（56 base + 364 增强变体） | 干净口径 56 阴性 |

- crop 尺寸：中位 391×338 px（p10~p90：116~890 × 158~456），min 8px 过滤后
  损失 170 个过小阳性框（0.13%）
- 每个 crop 保留溯源：patient / image_id / FDI / 框尺寸 / is_aug / is_dup（plaque_crops.csv）

## 7. 对建模的影响（数据→决策映射）

| 数据特性 | 采取的对策 |
|---|---|
| 类别 98:2 失衡 | 阴性 ×8 过采样 + 训练 val 重平衡 1:1 + Sens/Spec 口径（不用 Accuracy） |
| 无全阴性牙 | 放弃牙位聚合，改框级二分类 |
| 阴性评估样本稀缺 | 纳入增强变体阴性（分层 clean/extended 双口径报告） |
| 高分辨率源图 | crop 保留原生分辨率，训练时统一 224 |
| 患者级官方 split | 直接采用，零重划分 |

## 8. 与模型结果的呼应

- AUROC 0.895（test 干净框）→ 排序能力强
- Spec 0.554（n=56）→ 阴性样本太少所致的宽置信区间，非模型缺陷
- 接入牙齿分割的牙位 crop 路径 AUROC 0.9164 → 整牙 crop 比 GT 小条带更可分
