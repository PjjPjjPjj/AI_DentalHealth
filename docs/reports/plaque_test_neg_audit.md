## 3. Spec 语义上限估计

- 若疑似错标 ~4% 全部剔除：Spec 0.560 → **≈0.567**（几乎不动）
- 结论：**当前 Spec 0.56 的瓶颈不是标签噪声，是模型在极端光照/纹理下的真误报**
- 该阴性集的可达上限（模型理想时）≈ 0.95+；提升路径是曝光鲁棒性，不是清洗标签
