# 曝光鲁棒性实验：推理侧与训练侧均告负（阴性结果，含价值）

日期：2026-09-03；背景：420 阴性复审定位 FP 根因为"过曝/纹理捷径"，本轮验证两类修复
结论：**两条路都失败，原域框级 Spec 0.56 判定为接近该标注协议的信息上限；维持 v2 部署**

---

## 1. 推理侧预处理扫描（v2 不动，6 变体）

| 变体 | testExt Sens | Spec | AUROC | SANO Spec |
|---|---|---|---|---|
| **none（基线）** | 0.937 | **0.560** | **0.905** | **0.978** |
| clahe2 / clahe3 | 0.974 / 0.974 | 0.360 / 0.276 | 0.881 / 0.860 | 0.915 / 0.868 |
| grayworld | 0.792 | 0.357 | 0.663 ❌ | 0.887 |
| gw+clahe2 | 0.678 | 0.395 | 0.592 ❌ | 0.841 |
| gamma_auto | 0.939 | 0.493 | 0.890 | 0.973 |

失败机理：v2 的特征在**原始光照分布**上学习；推理侧改变分布=自造域移。
灰世界直接摧毁色彩先验（模型依赖牙面色相区分菌斑）。

## 2. 训练侧曝光增广（v4_expo，hsv_v 0.2→0.5 / hsv_s 0.4，从 v2 微调）

| | v2 | v4_expo |
|---|---|---|
| AUROC clean | 0.8958 | 0.8797 ❌ |
| testExt @0.70 | 0.937 / 0.560 | 0.950 / **0.343** ❌ |
| SANO @0.70 | 0.978 | 0.966 |

失败机理：HSV value jitter 是**线性增益**，而真实过曝是**像素剪切（死白）**，
合成增广不匹配真实退化模式；且强增广让模型整体更"宽容"，Spec 系统性下降。

## 3. 三轮"抬升原域框级 Spec"尝试汇总（全部失败）

| 尝试 | 结果 | 死因 |
|---|---|---|
| 托槽难阴性（v3_mined） | AUROC 0.896→0.835 | 与 GT 语义冲突 |
| 推理侧曝光归一化 | 全面回退 | 训练/推理分布不匹配 |
| 训练侧曝光增广（v4） | Spec 0.56→0.34 | 合成 jitter ≠ 真实过曝 |

**判定：原域框级 Spec ≈0.56 已接近该数据集标注协议（菌斑牙内子区域阴性）的信息上限。
残余 FP 本质是"菌斑环境上下文"（邻牙菌斑、龈缘、生物膜光泽）进入 crop 边缘的合法歧义。**

## 4. 最终立场与产物

- **部署维持 v2_sano + 校准 @0.746（≡raw 0.70）**：原域 Sens 0.937/Spec 0.560，
  SANO 健康 0.978，图级（mean-P）健康口 0/46 误报
- 框级指标定位：AUROC 0.90 的排序器 + 图级筛查由 mean-P 承担特异度
- 若继续抬框级，仅剩两条重路线：YOLO11m-cls 容量实验（低成本可试）、
  阴性协议升级（把"菌斑牙内子区域"从阴性集剥离，需要数据方重标）
- 产物：`outputs/plaque_exposure_sweep/sweep.{json,md}`、
  `runs/classify/.../plaque_bin_v4_expo/`、`scripts/train_plaque_bin_v4_expo.py`
